# TikTok Live Chat Log

Records live chat into a filterable log with pause, per-user filter and gift highlighting.

## Install

Follow the [install guide](https://github.com/chirag127/userscript-install-guide), then install:

```
https://github.com/chirag127/tiktok-live-chat-userscript/raw/main/tiktok-live-chat-userscript.user.js
```

## Usage

Open a live stream, press the 💬 chip (Alt+C), use Pause/CSV/JSON.

## Limits

- Only messages rendered while the panel is open are captured
- Gift detection is class-based
- Very busy chats drop rows past the 5000 cap

## Risk

Clean: read-only.
